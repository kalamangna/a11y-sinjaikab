Demo Widget Aksesibilitas Web Mandiri

Solusi ramah disabilitas web-component tanpa dependensi luar, seperti UserWay.

Uji Coba Fitur Aksesibilitas

Klik tombol mengambang ikon aksesibilitas di pojok kanan bawah untuk membuka panel pengaturan. Cobalah berbagai fitur berikut dan amati perubahannya secara instan:

  • Ukuran Teks: Memperbesar teks hingga +45%.
  • Mode Kontras: Uji mode Gelap, Terang, Invert, atau Monokrom.
  • Font Disleksia: Mengganti tipografi ke OpenDyslexic agar lebih mudah dieja.
  • Jarak Teks: Mengatur letter-spacing dan tinggi baris untuk kemudahan membaca.
  • Sorot Tautan: Menandai semua elemen tautan secara kontras.
  • Kursor & Garis Baca: Perbesar kursor mouse atau gunakan garis panduan horizontal membaca.
  • Hentikan Animasi: Mematikan semua pergerakan animasi CSS pada halaman.

Cara Pemasangan di Website Anda

Widget ini dirancang sangat praktis, cukup sertakan satu baris tag <script> di akhir berkas HTML atau layout master Anda:

<!-- Pasang di website manapun (HTML, PHP/CMS, Nuxt, Laravel, dsb) -->
<script 
  src="/path/to/widget.min.js" 
  data-position="bottom-right" 
  data-lang="id" 
  data-color="#0056b3" 
  defer>
</script>
